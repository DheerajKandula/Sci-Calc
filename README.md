# Sci-Calc
A simple CLI based scientific calculator completely written using Python and no libraries.
Takes inputs about the Operation and numbers and perfoms the selected Operation on them.

Functions :- 
    Basic Functions like Addition, Subtraction, Multiplication, Division, Modulus, Floor Division, Exponentiation, Root, e Power and 10 Power are all using Python in-built commands.
    
    Factorial :- A recursive Factorial function.
    
    Percentage :- Finds the percentage of a in b
    
    Logarithm :- Finds the log of any number with any given custom base.
    
    Sine :- Uses the MacLaurin series approximation formula for Sine to find the value of Sine at the given angle.

    Cosine :- Uses the MacLaurin series approximation formula for Cosine to find the value of Cosine at the given angle.

    Tangent :- Uses the MacLaurin series approximation formula for Tangent to find the value of Tangent at the given angle.

    ArcSine :- Uses the MacLaurin series approximation formula for ArcSine to find the value of ArcSine at the given angle.

    ArcCosine :- Uses the MacLaurin series approximation formula for ArcCosine to find the value of ArcCosine at the given angle.

    Tangent :- Uses the MacLaurin series approximation formula for ArcTangent to find the value of ArcTangent at the given angle.

    Note :- Sine, Cosine, Tangent, ArcSine, ArcCosine, ArcTangent will not give the exact values since for exact values using expansions, it needs to expand till infinity and that will cause Overflow.
